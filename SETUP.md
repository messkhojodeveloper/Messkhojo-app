# MessKhojo Flutter — Local Setup Guide

This file documents the **sensitive files that are intentionally excluded from version control**.
You must create these manually before building the app.

---

## 1. Firebase Configuration

### `lib/firebase_options.dart`
Generated by the FlutterFire CLI. Run:
```bash
dart pub global activate flutterfire_cli
flutterfire configure --project=mess-khojo-ag
```
This will auto-generate `lib/firebase_options.dart` and `android/app/google-services.json`.

### `android/app/google-services.json`
Download from [Firebase Console](https://console.firebase.google.com/) → Project Settings → Your Android app → Download `google-services.json`.
Place it at: `android/app/google-services.json`

---

## 2. Android Signing

### `android/key.properties`
Create this file at `android/key.properties` with the following content:
```
storePassword=<YOUR_KEYSTORE_PASSWORD>
keyPassword=<YOUR_KEY_PASSWORD>
keyAlias=<YOUR_KEY_ALIAS>
storeFile=app/<YOUR_KEYSTORE_FILENAME>.keystore
```

### `android/app/<name>.keystore`
The actual keystore file. Get this from the project owner (shared via secure channel — NOT git).

---

## 3. Android Local Properties

### `android/local.properties`
Auto-generated by Android Studio/Flutter SDK. If missing, create it:
```
sdk.dir=C:\\Users\\<YOUR_USERNAME>\\AppData\\Local\\Android\\sdk
flutter.sdk=C:\\<PATH_TO_FLUTTER>
```
Do NOT copy someone else's `local.properties` — the SDK paths are machine-specific.

---

## 4. Google Maps API Key

The Maps API key is stored in `android/local.properties`:
```
maps.api.key=<YOUR_MAPS_API_KEY>
```
Get the key from the project owner or Google Cloud Console.

---

## Quick Checklist Before Running

- [ ] `lib/firebase_options.dart` exists
- [ ] `android/app/google-services.json` exists
- [ ] `android/key.properties` exists (only needed for release builds)
- [ ] `android/app/*.keystore` exists (only needed for release builds)
- [ ] `android/local.properties` has correct SDK paths

Then run:
```bash
flutter pub get
flutter run
```
